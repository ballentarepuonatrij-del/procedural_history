# Фэнтези: летопись мира

Прототип генератора фэнтезийной истории для **Windows 10/11**, классический **Win32 Desktop / GDI**, **C++20**, без сторонних библиотек. Проект рассчитан на **Visual Studio 2026** с рабочей нагрузкой «Разработка классических приложений на C++», инструментами CMake и установленным Windows 10/11 SDK. Сборка использует доступный компилятор MSVC и SDK из вашей установки Visual Studio.

## Запуск из Visual Studio

1. Распакуйте архив и откройте папку `FantasyChronicle` в Visual Studio: **File → Open → Folder**.
2. Выберите CMake-предустановку **windows-debug** (или **windows-release**). В Visual Studio должны быть установлены компоненты C++ для классических приложений и CMake/Ninja.
3. Выберите запускаемый объект `FantasyChronicle.exe` и запустите его (**F5** или **Ctrl+F5**).
4. Если IDE не подхватила предустановки, откройте терминал **Developer PowerShell for VS** в папке проекта:

   ```powershell
   cmake -S . -B out/build/manual -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
   cmake --build out/build/manual --config Release
   .\out\build\manual\FantasyChronicle.exe
   ```

Исходники в UTF-8; для MSVC задан ключ `/utf-8`. Для линковки достаточно стандартных системных библиотек `user32`, `gdi32`, `comctl32`, `comdlg32`.

## Использование

- В стартовом экране выберите **1–28 стартовых цивилизаций**, **1–400 лет** и **зерно** генератора. При одинаковых значениях зерна и параметров мир воспроизводится идентично.
- Нажмите **«Создать мир»**. Симуляция рассчитывает историю на выбранный период и сохраняет снимок мира для каждого года.
- Окраска карты показывает текущие границы государств и области влияния. **Колёсико мыши** над картой меняет масштаб (100–1200%); увеличение привязано к точке под курсором. **Зажатая ЛКМ + перемещение** двигают увеличенную карту, не открывая окна по окончании перетаскивания.
- **Короткий щелчок ЛКМ** по окрашенной области открывает окно государства с культурой, правлением, населением и хронологией. **Щелчок по круглой метке** открывает **отдельную историю поселения** (города, деревни, замка, рощи, горного города, лагеря или скрытой общины). При масштабе от 200% появляются подписи поселений.
- В окне поселения показаны место, год основания, первоначальный и текущий владелец, благосостояние по выбранному году, список именных уроженцев и **собственная летопись**: строительство, ремёсла, ярмарки, бедствия, нападения, смена государственной принадлежности. На шкале времени эта информация обновляется одновременно с политическими границами.
- Если на карте слишком тесно и трудно выбрать точку, приблизьте карту колёсиком. Если государство исчезло, история его поселений не пропадает; в выбранном году они могут иметь другого владельца или быть независимыми.
- В окне государства выберите **жителя**, чтобы увидеть его профессию, социальное положение, членство в объединениях, **характеристики на выбранный год**, начальные параметры и личную биографию. Можно включить **умерших** жителей.
- Перемещайте **ползунок**, нажимайте **«◀ Год» / «Год ▶»** или **«▶ Пуск»**: карта, население, страна, правитель, поселения и биографии переключаются в выбранный год.
- **«Летопись в TXT»** сохраняет государства, их события, **отдельные летописи поселений** и биографии в UTF-8. **«Новый мир»** возвращает к стартовым условиям.

## Устройство

```text
FantasyChronicle/
├── CMakeLists.txt              Сборка ядра, Win32-приложения и теста
├── CMakePresets.json
├── include/Fantasy/World.h     Открытая модель данных + API симулятора
├── include/Fantasy/MapCamera.h  Независимая от Win32 камера: зум, перетаскивание, проекции
├── src/WorldTypes.cpp         Человекочитаемые названия перечислений
├── src/Names.h / Names.cpp    Имена, культуры, профессии, формы правления
├── src/Geography.cpp          Высоты, биомы, побережья, столицы
├── src/World.cpp              Государства, жители, поселения, годовые снимки и местная летопись
├── src/CharacterDevelopment.cpp Личность, обучение, возраст, последствия жизненных событий
├── src/Simulation.cpp         Войны, границы, демография, городские события, торговля,
│                             рабство, гильдии, отношения, восстания
├── src/Win32App.cpp           Win32 UI, GDI-карта, окна, ползунок, экспорт
├── examples/MagicPortentsModule.h  Пример подключаемого модуля магии
└── tests/smoke.cpp            Базовая проверка инвариантов генератора
```

Ядро **не использует Windows API**: доступно в виде `FantasyCore`, его можно впоследствии использовать с Direct2D, игровым движком, серверным генератором или иной оболочкой. Расширение поведения — отдельные методы `simulate...` в `Simulation.cpp`; новые расы, профессии, события — `World.h`, `WorldTypes.cpp` и `Names.cpp`.

### Базовая модель

- **Расы и культуры**: люди (античные государства, торговля и рабский труд), эльфы (леса, оборона), дварфы (горы, ремёсла и рабские рейды), разбойники/пираты (стоянки и картели), сказочный народец (лесные общины).
- **Мир**: острова/моря, равнины, леса, джунгли и горы; каждую клетку в каждый год контролирует государство либо никто.
- **Политика**: различные формы правления; расширение и потеря территорий; восстания с образованием новых государств; смена правителей.
- **Экономика и общества**: казна, устойчивость, торговые связи, поселения, ремесленные гильдии и контрабандные картели, рабство, освобождение.
- **Индивидуальная жизнь**: у каждого жителя есть ID, имя, раса, рождение, смерть, этапы профессии/сословия/государственной принадлежности, родное поселение, биография. **Характеристики** включают 6 способностей (сила, ловкость, интеллект, харизма, выносливость, сила воли), 8 навыков (военное дело, ремесло, торговля, знания, дипломатия, выживание, скрытность, целительство) и 5 черт характера (смелость, любознательность, честолюбие, сочувствие, дисциплина). Все показатели имеют диапазон 0–100, фиксируются при создании личности и развиваются по годам с историческими снимками `Person::development`. Опыт профессии, достижений, поездок, наставничества, личных отношений, пленения и освобождения меняет характеристики; накопленное лидерство влияет на выбор правителя. Есть взаимодействия **двух конкретных людей** (дружба, брак, соперничество, деловой союз, наставничество, преступление) с записью в обе биографии.
- **История**: для каждого года сохраняются карта территорий, состояние государств и **состояние существующих поселений**. Кроме того, каждый живой персонаж сохраняет показатели в конце каждого прожитого в симуляции года; умершие сохраняют последний известный снимок. Поселение хранит неизменный ID, координаты, основателя, вид и год основания; `SettlementYear` содержит владельца, благосостояние и число поимённо учитываемых уроженцев на каждый год. Местные события хранятся отдельно как `SettlementEvent`; смена владельца определяется при создании годового снимка даже после действий модулей. Можно отматывать время без повторного расчёта.
- **Интерактивная камера**: `fantasy::MapCamera` хранит масштаб и центр в мировых координатах; все метки, границы и обработка щелчков используют одну и ту же проекцию. Отдельный `MapRect` ограничивает видимую область карты; карта не смещается за края при панорамировании и изменении размера окна.

### Пределы прототипа

Это **работающий каркас**, а не законченный симулятор всех социальных процессов. Демография моделируется индивидуально, но с ограничением порядка **95–220 одновременно живущих персонажей на одно государство**, чтобы вся история оставалась доступной в памяти. Площадь клеток не переведена в реальные квадратные километры; экономика, благосостояние поселений и дипломатия пока вероятностные. **Отдельная модель адреса текущего проживания пока отсутствует:** список персонажей в окне поселения — уроженцы по привязке `homeSettlement`, а поле «учтённых уроженцев» считает тех из них, кто жив и числится в государстве, контролирующем поселение. Это не полная перепись фактического населения города. Названия/тексты генерируются из шаблонов, а не языковой моделью. Нет сложной генетики, родословных, товаров, маршрутов армий, полноценного поведения отдельного ИИ и сохранения симуляции в редактируемом формате. Экспорт TXT содержит летопись и биографии; для восстановления карты используйте те же начальные параметры и зерно.

**Модульный API уже работает:** реализован интерфейс `fantasy::IWorldModule` с хуками `onWorldCreated(World&)` и `onYear(World&, int)`, регистрация через `World::registerModule(...)`. Модуль может читать состояние через `liveOwners()`/`liveStates()` и расширять его с помощью `publishEvent`, `publishSettlementEvent`, `alterNation`, `claimTile`, `addPersonNote`, `grantExperience` (во время `onYear`, до сохранения снимка года). Пример в `examples/MagicPortentsModule.h` добавляет магическое знамение каждые 25 лет. Чтобы включить его, вызовите `world.registerModule(std::make_unique<MagicPortentsModule>());` перед `generate()` (например, в `Application::startGeneration`).

Для следующей версии логично добавить более богатые интерфейсы модулей (экономика, магия, религии, болезни, торговые пути) и бинарный/SQLite-формат сохранения снимков и персонажей.

## Проверка на Windows

1. Создайте мир и наведите мышь на середину карты; поверните колёсико вверх и вниз — участок под курсором должен оставаться примерно на месте, пока это позволяет край карты.
2. На масштабе 200% зажмите ЛКМ и потяните карту. Окно подробностей при перетаскивании не должно открываться; края карты нельзя вытянуть далеко за пределы экрана.
3. Щёлкните по круглой точке поселения: откроется его история. Щёлкните вне точки, внутри цветного государства: откроется история государства.
4. Не закрывая окно поселения, передвиньте шкалу годов: год, владелец, благосостояние и хроника должны измениться; более поздние события не должны быть видны в раннем году.
5. В окне государства выберите жителя и сравните характеристики при разных годах. Профессиональные навыки должны расти, события — влиять на черты характера, будущие изменения не должны появляться в прошлом. Умершие сохраняют показатели последнего года жизни.
6. Убедитесь, что текст в летописи прокручивается без наложений, и проверьте экспорт TXT — в нём есть раздел «Поселения и местная история», а также итоговые характеристики жителей.

## Тесты

На Windows можно запустить `FantasySmoke` или `ctest --test-dir out/build/windows-debug --output-on-failure`. Логика `FantasyCore` дополнительно собирается обычным C++20-компилятором на Linux для проверки независимости от Win32; само графическое приложение требует Windows.

## Развитие персонажей (новое)

- `Person::innate` — исходный профиль; `Person::current` — рабочий профиль текущего расчёта; `Person::development` — упорядоченные годовые записи `CharacterYear`. `World::statsAt(person, year)` возвращает профиль в историческом году, не раскрывая будущее.
- Обучение зависит от профессии, дисциплины и любознательности. При получении другой профессии меняется направление развития. Человек может сменить профессию по накопленному опыту; рабство и возраст ограничивают возможности обучения.
- В биографию записываются крупные жизненные рубежи и личные эпизоды. Небольшие ежегодные изменения фиксируются в характеристиках, чтобы летопись не засорялась повторяющимися строками.
- Интерфейс дополнений `World::grantExperience(personId, year, LifeExperience)` меняет характеристики при событиях из внешних модулей; вызывать его следует внутри `onYear`, пока рассчитывается соответствующий год. Для пояснения события можно отдельно использовать `addPersonNote`.
- Это **правила-приближения**, а не полноценная психологическая модель личности; здоровье, обучение детей, родословные и наследуемость предстоит развивать отдельно.
